# MIRA SDK skill file

[`SKILL.md`](SKILL.md) is the guide an AI assistant uses to build apps for MIRA glasses. It holds the SDK sources, the API reference, a working example and a validator. It's the same guide the MIRA app shares under **Instructions for making apps**.

## Use it

1. [Download SKILL.md](https://github.com/big-halo/mira-sdk/releases/latest/download/SKILL.md).
2. Start a new chat in **Claude** on claude.com, **Codex**, or **Claude Code**. On claude.com, use a chat that can run code and create files.
3. Attach `SKILL.md` to your prompt and describe your app.
4. Your assistant builds and checks the app, then gives you one `.html` file to add in the MIRA app.

ChatGPT.com isn't supported for building MIRA apps.

Step by step: [trymira.com/docs/quickstart](https://trymira.com/docs/quickstart)

## Updates

This copy updates automatically when the MIRA app's SDK changes, and [`skill.json`](skill.json) records when it last changed. Download it again before you start a new app, and keep the MIRA app up to date.
